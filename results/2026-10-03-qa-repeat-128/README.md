本次只有 6 道独立题，每个配置重复 10 轮；重复请求不能当成独立质量样本。结果不含公网延迟或浏览器绘制，也没有验证多人并发或生产 SLA。自然回答质量需结合原文人工核对；错误回答不能因为较快而算作可部署优化。

测量在 Windows 笔记本桌面环境进行，未锁定 GPU 时钟或隔离全部后台负载。这些数据属于本机描述统计，不是严格的跨硬件排名或置信区间。若比较 CPU FP32 与 GPU BF16，差别同时包含设备和精度变化；不能把它们的总速度差归因于注意力优化。
