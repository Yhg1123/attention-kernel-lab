# 已中止的服务结构诊断运行

**此目录不是正式三轮结果。** 固定推理线程版本的正式结果在 [../2026-10-01-qa-http-worker/](../2026-10-01-qa-http-worker/)。

最初的服务使用 ThreadingHTTPServer，并直接在每个请求新建的 HTTP 线程中执行模型。发现 cuDNN 持续出现较大的初始化开销后，中止了本次运行；`metadata.json` 没有 `completed_utc`，不得把此目录当作完成的基准。已写入的请求原样保留，`source/` 保存与 metadata 哈希一致的应用源码。

随后改为单个持续存活的推理线程，HTTP 线程只收发请求和文本事件。价格题的预检显示：重复自然回答的 cuDNN 总耗时由此前约 6–7 秒降至约 0.7 秒，但新的 KV 长度仍有初始化成本。这是服务结构和后端缓存复用的诊断证据，不是独立统计检验，也不能与最终三轮结果混合汇总。
